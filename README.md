# 📝 Ionic + Angular + Supabase: The Learning Curve

A modern, standalone mobile application built to document my journey through the **Ionic/Angular** ecosystem. This project serves as a practical sandbox for mastering **CRUD operations**, **Reactive Forms**, and **Real-time database integration** using **Supabase**.

## 🚀 The Vision
As a full-stack developer, my goal with this repository is to refine my technical skills in hybrid mobile development while applying the disciplined logic of **Stoic philosophy**—focusing on clean, efficient, and purposeful code.

## ✨ Features
* **User Authentication**: Robust Login and Logout system powered by Supabase Auth.
* **Standalone Architecture**: Built entirely with Angular Standalone Components (No NgModules) for a leaner, faster application.
* **Notes Management**:
    * **Create**: Quick-entry notes with real-time validation.
    * **Read**: Optimized dashboard with "Pull-to-Refresh" and local state management.
    * **Update**: Seamless editing experience using Reactive Forms.
    * **Delete**: (Planned/Implemented) Clean data removal with user confirmation.
* **Modern Dependency Injection**: Leveraging the `inject()` function for cleaner service handling.

## 🛠️ Tech Stack
* **Framework**: [Ionic 7.2+](https://ionicframework.com/) (Standalone)
* **Logic**: [Angular 16/17+](https://angular.io/)
* **Backend-as-a-Service**: [Supabase](https://supabase.com/) (PostgreSQL + Auth)
* **Styling**: SCSS / Ionic Utility Classes

## 📈 Learning Milestones
This project tracks my transition from traditional Angular patterns to modern practices:
1.  **Shift to Standalone**: Moving away from `AppModule` to component-based architecture.
2.  **Reactive over Template**: Mastering `FormGroup` for complex state management.
3.  **Lifecycle Mastery**: Understanding the nuance between Angular (`ngOnInit`) and Ionic (`ionViewWillEnter`) hooks to manage data flow for large record sets (scaling up to 12k+).
